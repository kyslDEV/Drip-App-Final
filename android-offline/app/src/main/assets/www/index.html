Drip Test App

Controle operacional de analise de gotejamento com pesagem inicial, agenda, pesagem final, laudos e banco de dados em uma experiencia guiada por perfil.

Como funciona

O monitor registra o contexto do lote, cadastra as amostras, acompanha o horario correto de analise e fecha a pesagem final. O sistema consolida os dados, calcula indicadores e prepara os laudos para rastreabilidade.

1. Cadastro do produto, lote, setor e monitor(a)
2. Pesagem inicial com calculo automatico
3. Agenda de analise e pesagem final
4. Laudos, sincronizacao e acompanhamento

Acesso por perfil

Escolha o perfil correto para liberar apenas o que faz sentido para cada pessoa. Monitor(a) executa a operacao, Supervisor(a) acompanha processos e laudos, e Dev/Admin gerencia dados, API e integracoes.

Voce pode voltar para esta tela a qualquer momento para trocar o perfil de acesso.
